# Student Mode example

This preset keeps projects, research interests, experience, publications, activities, and skills at the center of the page.

## Try it

1. Back up your current `data/site.js` if it contains personal changes.
2. Copy `examples/student/site.js` to `data/site.js`.
3. Open or refresh `index.html`.
4. Replace the fictional content in all `data/*.js` files.

The mode preview control is disabled in this example. Set `enableModePreviewSwitch: true` only when you want visitors to preview both layouts.
