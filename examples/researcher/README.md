# Researcher Mode example

This preset emphasizes biography, news, selected publications, the complete publication list, research projects, teaching, service, and awards.

## Try it

1. Back up your current `data/site.js` if it contains personal changes.
2. Copy `examples/researcher/site.js` to `data/site.js`.
3. Open or refresh `index.html`.
4. Replace every fictional record in `data/*.js` and update the SEO URL.

The example defaults to English and light mode and disables the public mode preview control. The same content files remain compatible with Student Mode.
