# Changelog

All notable changes to ScholarCanvas will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [1.0.0] - 2026-08-01

### Added

- Student and Researcher homepage modes with distinct layouts and visual systems.
- Bilingual Chinese and English content switching.
- Light, dark, and system theme support with persisted preferences.
- Configuration-driven profile, news, publication, project, experience, award, skill, teaching, and service sections.
- Publication tag filtering, author expansion, BibTeX copying, and selected-publication highlighting.
- Project cards, accessible project modal, and responsive Research Constellation visualization.
- Responsive desktop and mobile navigation.
- Keyboard navigation, skip links, focus management, ARIA states, reduced-motion support, and accessible toast notifications.
- SEO metadata, Open Graph, Twitter Card, canonical URL, JSON-LD, robots.txt, and sitemap.xml.
- GitHub Pages deployment and automated configuration validation.
- Student and Researcher examples, bilingual documentation, contribution guidelines, security policy, and repository templates.
- MIT License and GitHub Template Repository support.

### Fixed

- Corrected final-section navigation state in Researcher mode.
- Improved GitHub Pages subpath compatibility and live Demo links.
